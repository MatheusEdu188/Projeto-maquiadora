## 📌 Sobre o Projeto

Este projeto foi desenvolvido para uma maquiadora profissional, com o objetivo de atender às necessidades da cliente e, ao mesmo tempo, aprimorar minhas habilidades em **HTML, CSS e JavaScript**.

Embora o projeto não utilize JavaScript complexo ou pesado, as funcionalidades implementadas são suficientes para atender perfeitamente às exigências do site, garantindo uma experiência fluida e intuitiva para o usuário.

O site é totalmente **responsivo**, adaptando-se corretamente a dispositivos móveis e desktops.

Durante o desenvolvimento, pude aprofundar meus conhecimentos em **HTML e CSS**, especialmente em conceitos como **posicionamento, Flexbox** e boas práticas de estruturação. Busquei utilizar ao máximo **tags semânticas**, visando um código mais limpo, organizado e de fácil manutenção.

Atualmente, o projeto encontra-se **quase finalizado**, pronto para testes, ajustes finais e avaliação.
